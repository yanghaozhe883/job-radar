# 求职雷达 APP · 设计系统规范（Design Spec）

> 工程级设计基线。所有视觉、布局、动效以此为准；与 `方向总纲.md` §7 保持一致。Android（Compose）为本规范的第一落地端。
> 状态：**M1 · 设计定稿（文本规格）**。此文档可直接驱动 Compose 实现与后续高保真视觉稿。

---

## 1. 设计原则（Design Principles）

1. **雷达感**：贯穿"扫描 / 光 / 信号 / 精准"的视觉母题，让用户一眼知道"我在盯机会"。
2. **高级且克制**：深色科技质感为底，动效与辉光服务功能，绝不堆料。
3. **清晰优先**：信息密度高但层级分明，卡片/文字/标签永远可读（对比度 ≥ WCAG AA）。
4. **一次只做一件事**：每屏一个主行动（CTA），动效与视觉引导到主目标。
5. **触觉即反馈**：关键动作用触觉强化（收藏、投递、雷达"捕获"机会）。

## 2. 设计令牌（Design Tokens）

> 真实值以代码形式落地（Compose `Token.kt`），此处为语义基准。

### 2.1 色彩（Color）

**深色主题（默认）**

| Token | 值 | 用途 |
|-------|-----|------|
| `bg-primary` | `#0A0E17` | 全局背景（深空黑蓝） |
| `bg-secondary` | `#111827` | 二级背景 / 分区 |
| `surface` | `#151B29` | 卡片 / 面板底 |
| `surface-elevated` | `#1B2333` | 浮层 / 弹窗 |
| `surface-glass` | `rgba(255,255,255,0.06)` | 磨砂玻璃（毛玻璃底） |
| `surface-glass-strong` | `rgba(255,255,255,0.10)` | 高亮毛玻璃 |
| `primary` | `#2DE1C2` | 雷达绿 / 主行动 / 信号 |
| `primary-dark` | `#17A890` | 按压态 / 渐变端 |
| `accent` | `#6C7CFF` | 辉光蓝 / 次强调 |
| `accent-soft` | `#8B96FF` | 描边 / 辉光 |
| `success` | `#22D07E` | 匹配成功 / 正向 |
| `warning` | `#FFB020` | 提醒 / 中等匹配 |
| `danger` | `#FF5A6A` | 风险 / 删除 / 负向 |
| `text-primary` | `#FFFFFF` | 主文字 |
| `text-secondary` | `#8A94A6` | 次级文字 |
| `text-tertiary` | `#5A6474` | 辅助 / 占位 |
| `border` | `rgba(255,255,255,0.08)` | 分隔线 / 描边 |
| `overlay` | `rgba(0,0,0,0.6)` | 底部弹层遮罩 |

**浅色主题（可选，后期）**：将上述 Token 映射为亮色等价物（如 `bg-primary → #F5F6FA`），语义不变，动效一致。

**渐变**
- `radial-primary`: `#0A0E17 → #131C2B`（雷达背景，径向，暗部居中）
- `grad-primary`: `linear #2DE1C2 → #17A890`（主 CTA）
- `grad-glow`: `#6C7CFF → #2DE1C2`（辉光 / 强调描边）
- `grad-card`: `#1B2333 → #121826`（卡片玻璃底色）

### 2.2 字体系统（Typography）

| Token | iOS | Android | 用途 |
|-------|-----|---------|------|
| `display-large` | SF Pro 34 bold | Display 32/bold | 雷达标题 / 大数字 |
| `display-medium` | 28 semibold | 26/semibold | 页面主标题 |
| `title` | 22 semibold | 20/semibold | 卡片标题 |
| `body` | 17 regular | 16/regular | 正文 |
| `body-small` | 15 regular | 14/regular | 辅助正文 |
| `caption` | 13 medium | 12/medium | 标签 / 时间 |
| `label` | 12 semibold | 11/semibold | 徽章 / 小字段 |

- 行高：正文 1.4–1.5，标题 1.2。
- 数字（薪资 / 匹配分）用等宽数字（`tabular-nums` / Compose `FontFeature`），保证对齐。

### 2.3 间距网格（Spacing）

以 **4pt** 为基准：
`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64`
页面左右安全边距 `16`，卡片内边距 `16`，卡片间距 `12`。

### 2.4 圆角（Corner Radius）

| Token | 值 | 用途 |
|-------|-----|------|
| `radius-sm` | `8` | chips / 徽章 |
| `radius-md` | `12` | 子卡片 / 输入框 |
| `radius-lg` | `16` | 主卡片 |
| `radius-xl` | `20` | 弹窗 / 底部弹层 |
| `radius-full` | `999` | 按钮 / 圆形雷达 / 头像 |

### 2.5 阴影 / 辉光（Elevation & Glow）

| Token | 值 | 用途 |
|-------|-----|------|
| `shadow-card` | `0 8 24 rgba(0,0,0,0.45)` | 卡片浮起 |
| `glow-primary` | `0 0 24 rgba(45,225,194,0.45)` | 主 CTA 辉光 |
| `glow-accent` | `0 0 20 rgba(108,124,255,0.40)` | 强调辉光 |
| `blur-glass` | `backdrop-blur(20)` / `RenderEffect blur 20` | 毛玻璃 |

> 辉光只在关键元素（主动作 / 雷达发射 / 匹配成功）使用，避免全局光污染。

### 2.6 动效令牌（Motion Tokens）

| Token | 值 | 用途 |
|-------|-----|------|
| `duration-fast` | `120ms` | 按压 / hover / 小反馈 |
| `duration-base` | `240ms` | 常规转场 / 淡入 |
| `duration-slow` | `400ms` | 页面切换 / 雷达扫描 |
| `duration-radar` | `1600ms` | 雷达扫描周期 |
| `ease-out` | `cubic-bezier(0.2,0,0,1)` | 默认出场（快出缓停） |
| `ease-in-out` | `cubic-bezier(0.4,0,0.2,1)` | 常规过渡 |
| `spring-card` | `damping 0.55 · stiffness medium-low` | 卡片/按钮回弹（签名"bouncy"） |
| `spring-micro` | `damping 0.70 · stiffness medium` | Tab / chip 等小元素 |
| `spring-pop` | `damping 0.45 · stiffness medium` | 检测等强调瞬间 |

> **真机已调**：`JobRadarMotion` 为唯一权威实现（`Shape.kt`）。卡片 3D 倾斜收敛到 `7°`（克制），
> 弹簧 stiffness 用 `MediumLow`（2-3 次振荡收敛，不无限回弹）；雷达页新增内圈**反向旋转虚线环**
> 营造纵深；检测触发用 `popSpring` 外扩光弹。主帧预算 <16ms，雷达页独立优化。

## 3. 图标与图形语言

- **图标**：线性 outline 图标（描边 1.5px），统一用 `Material Symbols`（Android）/ `SF Symbols`（iOS），确保一致性。
- **雷达母题**：核心图标为雷达/扫描符号，用于 Tab1 和启动页。
- **匹配可视化**：技能匹配用小雷达图 / 进度环（`Canvas` 绘制），见 §5。
- **粒子 / 辉光**：仅雷达页与匹配成功瞬间使用。

## 4. 组件规范（Component Spec）

> 每个组件给出：结构、状态（normal/pressed/disabled）、动效、落地注意。

### 4.1 主按钮 `PrimaryButton`
- 结构：`grad-primary` 渐变底 + 圆角 `radius-full` + `display` 主文字 + `glow-primary` 辉光。
- 状态：pressed → 收缩至 `0.96` + `duration-fast`；disabled → 降透明 `0.4`。
- 高度 `52`，左右 `24`。

### 4.2 雷达卡片 `JobCard`（Tab2 机会流 / Tab1）
- 结构：`surface-glass` 毛玻璃底 + `border` 描边；左侧公司 logo，中部标题/薪资/标签，右侧匹配分圆环。
- 三级标签（chips）：薪资（primary 描边）、岗位类型、经验/学历（灰）。
- 动效：进入 `ease-out` 浮现；3D 卡片滑动（见 §5 机会流）。

### 4.3 匹配分环 `MatchRing`
- `Canvas` 绘制圆环，`grad-glow` 描边 + 中心数字（等宽字体）。
- 颜色映射：≥80 `success` / 60–79 `primary` / 40–59 `warning` / <40 `text-tertiary`。
- 动效：进入时 `ease-out` 由 0 增长到目标值，数字随环 scrolled。

### 4.4 筛选 Chips `FilterChip`
- 单选/多选；选中 `primary` 填充 + 白文字，未选中 `surface` + 灰文字 + `border`。
- 动效：选中/取消 `ease-out` 过渡（宽度/背景平滑）。

### 4.5 底部 Tab Bar `BottomNav`
- 4 Tab（雷达/机会/收藏/我的）；当前 Tab 用 `primary` 高亮 + 上方 tiny glow + 图标微放大（`scale 1.15` + `spring`）。
- 透明毛玻璃底（`surface-glass` + `blur-glass`），悬浮于内容之上。

### 4.6 雷达中央控件 `RadarCore`（Tab1）
- 圆形雷达屏（`Canvas`）：同心扫描环 + 旋转扫掠线 + 粒子点，周期性 `duration-radar`。
- 中央显示"正在盯 X 类职位"+ 状态文字。
- 新机会捕获：中心向外爆发光晕 + 卡片从雷达"照出"上浮。

### 4.7 空态 / 加载 / 错误
- 空态：暗淡雷达图标 + 一句引导文案 + 主 CTA。
- 加载：雷达随动 spinner / 骨架屏（`surface` 占位 + 呼吸动画）。
- 错误：`danger` 图标 + 文案 + 重试按钮。

## 5. 页面布局与炫技动效规格

> 图式为 wireframe（文字示意）。

### 5.1 登录 / 启动
- 启动页：全屏 `radial-primary` 背景 + 雷达 Logo 波纹扩散 + 品牌 Slogan 渐入。
- 登录：手机号 + 验证码；主按钮 `PrimaryButton`；底部协议文案。

### 5.2 Tab1 雷达页（产品心脏）
```
┌─────────────────────────────┐
│  [顶部] 城市 ▾   ·  目标岗位 ▾ │   (筛选 chips)
│                             │
│            ◉◉◉             │   RadarCore: 扫描波纹/粒子弹
│            雷达屏            │   中央: "正在盯 前端/测试/算法"
│        (持续扫描动画)         │
│                             │
│  ███  新机会·前端工程师       │   ← 捕获弹出(从雷达照出)
│      上海 · 25-35K · 匹配92%  │
│                             │
│  [底部 4 Tab] 雷达|机会|收藏|我的│
└─────────────────────────────┘
```
**炫技**：`RadarCore` `Canvas` 滚动扫掠线 + 粒子；捕获新机会时中心光晕爆发、卡片玻璃上浮 + 触觉 `VibrationEffect`。

### 5.3 Tab2 机会流
```
┌─────────────────────────────┐
│  搜索框 (毛玻璃)   +  筛选▾   │
│  排序: 综合|最新|薪资|匹配     │
│                             │
│  ┌─────────────────────────┐│
│  │ 职位卡1 (毛玻璃+圆环)     ││  ← 卡片 3D 滑动 / 擦除
│  └─────────────────────────┘│
│  ┌─────────────────────────┐│
│  │ 职位卡2                  ││
│  └─────────────────────────┘│
└─────────────────────────────┘
```
**炫技**：卡片横向 3D 滑动（`graphicsLayer` rotationY/translationZ）+ 弹簧回弹；滑动擦除偏好（左滑收藏/右滑隐藏）；列表中匹配分环渐入。

### 5.4 职位详情页
```
┌─────────────────────────────┐
│ ┌─ 顶部头图(毛玻璃blur)──────┐│
│ │ 公司logo + 名称 + 规模城市   ││
│ └───────────────────────────┘│
│  职位标题   ·  薪资          │
│  标签: 类型/经验/学历         │
│  ┌─ 技能匹配 ──────────────┐│
│  │  (技能雷达图/进度环)      ││
│  └─────────────────────────┘│
│  JD 描述 (逐段渐入)          │
│  ───────────────────────────│
│  [收藏]   [立即投递(主CTA)]  │
└─────────────────────────────┘
```
**炫技**：顶部毛玻璃头图（`RenderEffect` blur）随滚动切换；JD 文本块渐入（`ease-out`）；技能匹配用 `Canvas` 雷达图/进度环动画；从机会流点击时**共享元素转场**（头像/标题平滑过渡）。

### 5.5 Tab3 收藏 / 投递记录
- 列表：收藏 / 已投 / 已隐藏 分段（segmented chips）。
- 状态流转动效：投递后卡片打勾 + `success` 光晕 + 触觉。

### 5.6 Tab4 我的
- 顶部：头像 + 昵称 + 目标岗位。
- 列表：偏好设置 / 简历 / 通知 / 关于 / 退出。

## 6. 可访问性（Accessibility）

- 文字对比度 ≥ 4.5:1（正文）/ 3:1（大字），深色下校验 `text-secondary`。
- 触区 ≥ 48×48dp。
- 支持动态字体 / 深色、浅色主题切换。
- 动效尊重系统「减少动态效果」(`reduced motion`)：仅保留必要的 240ms 常规过渡，关闭粒子/扫掠。

## 7. 性能预算

| 指标 | 值 |
|------|-----|
| 首屏 FPS | 稳定 ≥ 55 |
| 主帧耗时 | <16ms |
| 雷达页 | 独立优化，`Canvas` + 离散动画 |
| 冷启动 | 目标 <1.2s |

## 8. 落地映射

| Token / 组件 | Android (Compose) | iOS (SwiftUI) |
|--------------|-------------------|---------------|
| 色板/渐变 | `Color` + `Brush` | `Color` + `LinearGradient` |
| 文本 | `MaterialTheme.typography` | `Font` + 语义缩放 |
| 毛玻璃 | `Modifier.blur`(RenderEffect) | `.ultraThinMaterial` |
| 动效 | `animate*AsState` + `graphicsLayer` + `spring` | `withAnimation` + `matchedGeometryEffect` |
| 共享元素 | `SharedTransitionLayout` | `matchedGeometryEffect` |

> 所有 Token、组件、动效在双端语义一致，仅实现 API 不同。
